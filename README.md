# Astro Builder

A Mac app for visually editing Astro sites. This repository only holds the builds.

## Install

1. Download **Astro-Builder.dmg** from the [latest release](https://github.com/sleeplesskxng/astro-builder-releases/releases/latest).
2. Open it and drag Astro Builder into Applications.
3. Open Astro Builder. macOS will say it can't verify the developer.
4. Go to System Settings, then Privacy & Security, and click **Open Anyway** next to the message about Astro Builder.

After that it opens like any other app, and updates itself: a new version downloads in the background and runs from the next launch.

Needs a Mac with Apple silicon (M1 or later) and macOS 13 or later.
